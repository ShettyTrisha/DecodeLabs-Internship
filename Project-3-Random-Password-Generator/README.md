#  Random Password Generator

##  Project Overview
The Random Password Generator is a Python-based project
that generates random and complex passwords based on
the length specified by the user.

It includes uppercase letters, lowercase letters,
numbers, and special characters to help create
stronger passwords.

##  Features
- User-defined password length
- Uppercase and lowercase letters
- Numbers and special characters
- Random password generation
- Input validation for password length
- Simple and user-friendly interface

##  Technologies Used
- Python
- Random Module
- String Module

##  Requirements
- Python 3.x
- Visual Studio Code (optional)

##  How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Run the following command in the terminal:

   python password_generator.py

4. Enter your desired password length.
5. View your generated password.

##  Sample Output

===== RANDOM PASSWORD GENERATOR =====

Enter the password length: 10

Your generated password is: aT7@kP2#mQ
