#  General Knowledge Quiz

##  Project Overview
The General Knowledge Quiz is a simple Python-based quiz
game that tests the user's general knowledge through
three questions.

The program checks the user's answers, awards one point
for each correct answer, and displays the final score
at the end of the quiz.

##  Features
- Three general knowledge questions
- Interactive user input
- Automatic answer checking
- Score tracking
- Final score displayed out of 3
- Feedback based on the final score
- Case-insensitive answer checking
- Removes unnecessary spaces from answers

##  Technologies Used
- Python 3
- If-Else Statements
- Variables
- User Input and Output
- String Manipulation

##  Requirements
- Python 3.x
- Visual Studio Code (optional)

##  How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

   python general_knowledge_quiz.py

5. Answer all three questions.
6. View your final score.
