# Personal Expense Tracker

## Project 2 - DecodeLabs Internship

A Python-based Expense Tracker that allows users to record and manage their daily expenses.

## Features

- Add new expenses
- Select expense categories
- Add a short description
- View all expenses
- Calculate total amount spent
- View category-wise spending
- Delete an expense
- Handle invalid input

## Technologies Used

- Python

## How to Run

1. Download or clone this repository.
2. Open the project in VS Code.
3. Run `expense_tracker.py`.
4. Follow the menu displayed in the terminal.

## Project Objective

The main objective of this project is to understand data accumulation, mathematical operations, lists, dictionaries, functions, loops, and conditional statements in Python.
